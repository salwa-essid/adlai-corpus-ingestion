# ADLAI Corpus Ingestion Pipeline

A Node.js service responsible for reading the output generated by the ADLAI Scraper, validating the extracted legal articles, and preparing them for ingestion into a PostgreSQL database.

This project acts as the bridge between the scraping service and the ADLAI legal corpus database.

---

## Features

- Read scraper manifest file
- Read legal article JSON files
- Validate article data before processing
- Generate ingestion statistics
- Modular service architecture
- Ready for PostgreSQL integration

## Services

### manifestService

Reads the scraper manifest and returns the list of available legal sources.

---

### articleReaderService

Loads article JSON files from the output directory.

---

### validationService

Performs validation before processing articles.

Current validations:

- JSON must be an array
- Source must contain articles
- First article must contain text
- Reject website chrome such as:
    - Government Website Registered
    - Privacy Policy
    - Cookies
    - Skip to Content

---

### ingestionService

Coordinates the entire ingestion process by:

- Reading the manifest
- Loading article files
- Validating article data
- Generating statistics
